🌍 SIATA - Calidad del Aire

Sistema de Monitoreo de Material Particulado PM2.5 en el Valle de Aburrá

📋 Problema y Contexto

Problema: La contaminación del aire por material particulado PM2.5 representa un riesgo significativo para la salud pública en el Valle de Aburrá. Las personas vulnerables (niños, adultos mayores y personas con enfermedades respiratorias) necesitan información actualizada para tomar decisiones sobre sus actividades diarias.

Contexto: El SIATA (Sistema de Alerta Temprana de Medellín y el Valle de Aburrá) opera una de las redes de monitoreo de calidad del aire más sólidas del país, con 43 puntos de monitoreo entre automáticos y manuales, especialmente para material particulado PM2.5 [[22]].

Necesidad: La Secretaría de Salud Municipal requiere un sistema que permita:

  • Consultar información actualizada en tiempo real
  • Identificar zonas críticas de contaminación
  • Visualizar geográficamente la distribución del contaminante
  • Generar alertas tempranas y recomendaciones
  • Apoyar la toma de decisiones en salud pública

📊 Datos Utilizados

Fuente: SIATA - Sistema de Alerta Temprana de Medellín y el Valle de Aburrá

API: https://siata.gov.co/EntregaData1/Datos_SIATA_Aire_AQ_pm25_Last.json

Variable principal: Material particulado PM2.5 (µg/m³)

Cobertura: 525 estaciones de monitoreo

Actualización: Datos horarios en tiempo real

Variables disponibles:

  • estacion: Nombre de la estación de monitoreo
  • pm25: Concentración de material particulado PM2.5 (µg/m³)
  • ica: Índice de Calidad del Aire calculado
  • categoria: Clasificación de la calidad del aire
  • latitud/longitud: Coordenadas geográficas
  • fecha_local: Fecha y hora de la medición
  • recomendacion: Recomendación de salud

⚙️ Funcionamiento de la Solución

Flujo de Procesamiento:

  1. Consumo de API: Conexión HTTP a la API de SIATA para obtener datos en tiempo real
  2. Transformación: Conversión de JSON a DataFrame de pandas
  3. Limpieza: Manejo de valores nulos y datos inválidos (-9999)
  4. Cálculo del ICA: Conversión de µg/m³ a Índice de Calidad del Aire usando estándares EPA/SIATA
  5. Clasificación: Asignación de categorías y colores según rangos ICA
  6. Generación de alertas: Identificación automática de estaciones críticas
  7. Visualización: Mapas interactivos con folium y gráficos estadísticos

Componentes:

  • API Consumer: requests library para consumo de datos
  • Data Processing: pandas y numpy para transformación
  • Visualización: matplotlib, seaborn y folium
  • Interactividad: Widgets de IPython para filtros
  • Mapeo: Folium con MarkerCluster para visualización geográfica

💡 Utilidad para la Toma de Decisiones

Para la Secretaría de Salud:

  • Identificación de zonas prioritarias para intervenciones
  • Emisión de alertas sanitarias preventivas
  • Planificación de campañas de salud pública
  • Asignación de recursos a áreas críticas

Para la Población:

  • Decidir si realizar actividades al aire libre
  • Proteger a grupos vulnerables (niños, adultos mayores)
  • Planificar rutas de movilidad evitando zonas contaminadas
  • Uso preventivo de mascarillas en zonas críticas

Para Instituciones Educativas:

  • Decidir suspensión de actividades deportivas externas
  • Implementar protocolos de protección
  • Informar a padres de familia

🗺️ Visualizaciones Disponibles

El sistema incluye las siguientes visualizaciones:

  • Histogramas: Distribución de concentraciones PM2.5
  • Gráficos de barras: Comparación entre estaciones
  • Boxplots: Análisis estadístico de distribución
  • Tablas dinámicas: Consultas filtradas por categoría o ubicación

✅ Conclusiones

  • Las alertas automáticas permiten respuesta rápida ante episodios críticos
